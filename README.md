# DelXPost

X Tweet Cleaner（Chrome 插件）

按关键字批量删除自己在 X/Twitter 上的推文。

## 安装
1. Chrome 打开 `chrome://extensions`，右上角开启「开发者模式」
2. 点「加载已解压的扩展程序」，选择本文件夹 `x-tweet-cleaner`
3. 已打开的 x.com 标签页需要刷新一次

## 使用
1. 点击插件图标，确认设置：
   - 匹配字符串：`http://ccs0919.pixnet.net`（匹配时忽略 http:// / https:// 和大小写）
   - 删除间隔：2 秒
   - 每批数量：200，批间暂停：10 分钟
   - 总上限：0 = 不限（**首次建议设为 3 测试**）
2. 点「① 打开搜索结果页」，会打开 `from:你的用户名 痞客邦` 的最新搜索结果
   （也可以直接在个人主页上运行，但 2011 年的旧推要滚动很久）
3. 在该页面点「② 开始删除」。右上角会出现悬浮面板，显示进度/倒计时，可随时停止

## 推文很多时（几千条）：按时间段自动删除
X 的搜索结果每次只返回一部分，滚到底就没了。插件现在有两种处理方式：
- **自动刷新**（默认开启）：本页没有匹配推文时会自动刷新页面，加载新的结果继续删。
  连续刷新「N 次」都删不到任何一条，才认为删完了
- **按时间段**：在弹窗里设好「开始日期 / 结束日期 / 每段天数」，点「按时间段自动删除」。
  插件会依次搜索 `from:用户名 搜索词 since:… until:…`，删完一段自动跳到下一段。
  「当前进度」显示正在删第几段，中断后可以从这一段接着删
- 日期范围尽量设得准一点（例如只设推文实际存在的年份），这样能少跑很多空的时间段

## 说明
- 原理：模拟点击 推文「…」→「删除」→「确认」，只会删除正文包含关键字的推文；
  菜单里没有「删除」项（如别人的推文/转推）会自动跳过
- 页面上找不到匹配项时会自动下滑加载；搜索页显示“重试”时会自动点击
- 每批暂停结束后会刷新页面再继续
- 连续 5 次删除失败视为被限流，自动暂停一个批次间隔，然后刷新页面继续
- 同一标签页刷新后会自动继续（包括暂停倒计时）
- 请只在一个标签页运行；暂停期间标签页需保持打开（可放在后台）

## 批量查询粉丝数（精确值）
X 页面上显示的是缩写（如 1K），插件读取的是 X 返回的原始数据，可以看到精确值（如 1,052）。
1. 点插件图标，在最下方「批量查询粉丝数」里每行填一个账号 ID（可带 @ 或主页链接）
2. 点「查询粉丝数」。插件会在后台临时打开一个标签页依次打开每个主页，查完自动关闭
3. 结果显示在弹窗表格里；关掉弹窗也会继续查，重新打开即可看到结果
- 需要浏览器已登录 x.com；每个账号约 3–5 秒，建议一次 15 个以内
